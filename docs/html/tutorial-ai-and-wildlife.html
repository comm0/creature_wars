    Tutorial 10: AI Opponents and Wildlife

    The computer races use the same economy, actions and orders as the player. Only the decisions come from code.

    Facts

    Before each decision the core collects what the AI needs:

        ai_context_t context{
        .gold_ = controller_p.state_.gold_.amount_,
        .food_ = controller_p.state_.food_.amount_,
        .base_level_ = base->level(),
        .base_health_ = base->health(),
        .base_max_health_ = base->stats().max_health_,
        .neutral_target_available_ = neutral_target.has_value()
    };

    Decisions

    ai_planner_t is a pure function. The rules in short:

    1. Enemies near the base: defend, spawn units.
    2. Army too small: spawn more.
    3. Low on resources and a wild creature close by: go hunting.
    4. Army big enough: attack an enemy base.
    5. Spare resources: training, upgrades, research.

    The first rule in code:

        const auto under_attack = context_p.nearby_enemy_count_ > 0
        || context_p.base_health_ * 100 < context_p.base_max_health_ * 70;

    if (under_attack) {
        decision.strategy_ = ai_strategy_t::defend;
        const auto* spawn = select_spawn(profile_p, context_p, actions_p, true, false);
        if (spawn != nullptr) {
            decision.action_key_ = spawn->key_;
        }
        return decision;

    Difficulty

    Easy, normal and hard use the same planner with other numbers from data/ai_profiles.json:

        "hard": {
      "decisionIntervalMs": 750,
      "goldReserve": 8,
      "foodReserve": 0,
      "minimumArmyForGrowth": 2,
      "minimumArmyForAssault": 2,
      "maximumSpawnQueue": 3,
      "huntGoldBelow": 100,
      "huntFoodBelow": 8,
      "huntMaximumDistance": 18
    }

    Wildlife

    wildlife_spawner_t plans deer, wolves and troll lairs on the scheduler, each time near another race:

    void wildlife_spawner_t::start(game_scheduler_t::time_point_t time_p)
{
    reset();
    const auto generation = generation_;
    schedule_deer(time_p + deer_initial_delay, generation);
    schedule_wolf(time_p + wildlife_spawn_interval, generation);
    schedule_lair(time_p + lair_spawn_interval, generation);
}

    A killed wild creature pays a reward. It is split between the races by the damage they dealt. Hunting pays, but it leaves your base open.
