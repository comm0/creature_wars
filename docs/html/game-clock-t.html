    game_clock_t Class

    Translates wall time into game time. More...

    Header: #include <game_clock_t>

    Detailed Description

    The scheduler and creature movement work in game time. The clock starts paused, follows the wall clock while the game runs, stops while it is paused and runs faster or slower when the time scale changes. wall_time_for() converts a game time back to the wall time the game thread has to sleep until.

    See also game_scheduler_t.
