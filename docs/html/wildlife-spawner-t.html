    wildlife_spawner_t Class

    Schedules wild creatures and troll lairs during a match. More...

    Header: #include <wildlife_spawner_t>

    Detailed Description

    The spawner plans each kind of wild creature on the game scheduler and places it near a different race each time. reset() starts a new generation, which makes every event planned for an older match do nothing when it fires.
