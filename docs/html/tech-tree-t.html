    tech_tree_t Class

    Base upgrades and research paths loaded from data/tech_tree.json. More...

    Header: #include <tech_tree_t>

    Detailed Description

    Each research path has an id, a name, an effect and one entry per level. A level needs a minimum base level and costs gold and time. The effect value is applied to the base or to the units around it, for example extra regeneration, more health or more shots per turn.

    See also base_orders_t.
