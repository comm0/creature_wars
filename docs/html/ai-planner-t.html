    ai_planner_t Class

    Decides what a computer controlled race does next. More...

    Header: #include <ai_planner_t>

    Detailed Description

    plan() is a pure function. It takes the settings of the difficulty profile, a summary of the race's situation and the list of actions its base currently offers, and returns a strategy (recover, grow, defend, hunt, rally or assault), an optional base action and whether to send units hunting or attacking. Because it has no state it is easy to test and easy to reason about.

    The difficulty profiles come from data/ai_profiles.json.
