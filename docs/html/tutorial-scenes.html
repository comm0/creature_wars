    Tutorial 4: Scenes and the Game Window

    Felgo splits a game into one GameWindow and several Scene items. We have three scenes: menu, game and game over.

    GameWindow

    GameWindow {
    id: gameWindow

    required property var gameBackend

    screenWidth: 1280
    screenHeight: 720
    storeWindowGeometry: false
    activeScene: menuScene
    state: "menu"

    screenWidth and screenHeight only matter on desktop. On phones the window fills the screen.

    A scene with a fixed size

    Design every scene for one size. Felgo scales it to the screen:

        width: 640
    height: 360
    scaleMode: "letterbox"

    With letterbox the aspect ratio stays the same and free space becomes bars. To fill the bars too, anchor backgrounds to gameWindowAnchorItem:

    Rectangle {
    anchors.fill: gameScene.gameWindowAnchorItem
    color: "#111814"
}

    Switching scenes

    Hide every scene by default and show the right one with a state on the window:

        states: [
        State {
            name: "menu"

            PropertyChanges {
                menuScene.opacity: 1
                gameWindow.activeScene: menuScene
            }
        },
        State {
            name: "game"

            PropertyChanges {
                gameScene.opacity: 1
                gameWindow.activeScene: gameScene
            }
        },
        State {
            name: "gameOver"

            PropertyChanges {
                gameScene.opacity: 1
                gameOverScene.opacity: 1
                gameWindow.activeScene: gameOverScene
            }
        }
    ]

    Each scene has this, so the change fades in and out:

    opacity: 0
visible: opacity > 0
Behavior on opacity { NumberAnimation { duration: 250 } }

    Switching is one line:

    gameWindow.state = "game"

    The menu

    The menu shows one card per race and a Felgo AppButton. Each card shows the first frame of a sprite sheet:

    TexturePackerAnimatedSprite {
    source: "qrc:/assets/creatures/orc/orc.json"
    frameNames: ["south_0.png"]
}
