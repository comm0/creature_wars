    Core Reference

    The most important classes of Creature Wars, grouped by layer. The game core uses snake_case names with a _t suffix, the Qt bridge uses Qt style names.

    Game core

    ClassRole
    game_tOwns the game thread, the world and the match rules.
    game_event_dispatcher_tRuns queued tasks in arrival order.
    game_scheduler_tHolds events planned for a point in game time.
    game_clock_tTurns wall time into game time with pause and speed.
    base_orders_tRuns timed base orders with one queue per action.
    tech_tree_tBase upgrades and research paths loaded from data.
    ai_planner_tPicks the next strategy and action for a computer race.
    wildlife_spawner_tSchedules deer, wolves and troll lairs during a match.
    igame_observer_tInterface through which the core reports changes.

    Qt bridge

    ClassRole
    GameObserverMoves core events to the GUI thread as Qt signals.
    GameBackendThe object QML talks to: properties, models and commands.
