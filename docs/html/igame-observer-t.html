    igame_observer_t Class

    The interface through which the game core reports every change of the world. More...

    Header: #include <igame_observer_t>
    Inherited By:

    GameObserver

    Detailed Description

    The core calls these functions on the game thread whenever something changes: a creature appears, moves, gets hit or dies, a base changes, a player's resources change or the match ends. The interface uses plain C++ types only, so the core stays independent of Qt.

    GameObserver implements it for the QML client. A network server could implement it by serializing the events for connected clients.

    See also GameObserver and game_t.
