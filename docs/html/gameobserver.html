    GameObserver Class

    Moves events from the game thread to the GUI thread. More...

    Header: #include <GameObserver>
    Inherits: igame_observer_t

    Detailed Description

    GameObserver implements igame_observer_t. Every call copies the data it needs and posts a queued call to the GUI thread, where it emits a Qt signal. GameBackend and the list models connect to these signals.
