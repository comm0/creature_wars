    Tutorial 11: Ending the Match

    Rules

    A destroyed base knocks its race out and kills its creatures. Troll lairs do not count. After each destroyed base the core checks:

        if (!player_base_alive) {
        end_match(false);
    } else if (!enemy_base_alive) {
        end_match(true);
    }

    Ending the match stops wildlife and all order queues, then reports the result:

    void game_t::end_match(bool victory_p)
{
    match_active_ = false;
    wildlife_spawner_.reset();
    for (auto& controller : controllers_) {
        controller->orders_->clear();
    }
    publish_base_actions();
    observer_->on_match_ended(
        victory_p,
        std::chrono::duration_cast<std::chrono::milliseconds>(
            current_time() - match_started_at_
        )
    );
}

    The game over scene

    QML gets the matchEnded signal and switches state:

            function onMatchEnded(victory, durationMs) {
            gameOverScene.victory = victory
            gameOverScene.durationMs = durationMs
            gameWindow.state = "gameOver"
        }

    GameOverScene is a third scene with a see through background, so the battle stays visible behind it. Two AppButton items offer Play again and Main menu.

    Effects with EntityManager

    Mages hit a 3 by 3 area. Each hit spawns a short explosion through Felgo's EntityManager:

        function showAreaAttack(column, row, radius, color) {
        entityManager.createEntityFromComponentWithProperties(areaExplosionComponent, {
            x: (column - radius) * root.tileSize,
            y: (row - radius) * root.tileSize,
            tileSize: root.tileSize,
            radius: radius,
            color: color,
            gameTimeScale: root.gameTimeScale
        })

    The explosion is an EntityBase that removes itself when its animation ends:

            ScriptAction {
            script: explosion.removeEntity()
        }
