    Tutorial 3: The Felgo Project

    A Felgo game is a Qt app with a few extra pieces. Here is what they are.

    Folders

    FolderContent
    backendC++ game core and the classes that expose it to QML
    qmlFelgo scenes and QML components
    dataGame rules in JSON
    assetsSprites and images

    CMake

    The core is a plain library. The app target adds QML, data and shaders:

        qt_add_executable(appCreatureWars
        main.cpp
        ${ApplicationFiles}
        ${QmlFiles}
    )

    qt_add_resources(appCreatureWars creature_wars_data
        PREFIX "/"
        FILES
            data/creature_types.json
            data/base_types.json
            data/economy.json
            data/tech_tree.json
            data/ai_profiles.json
            ${AssetFiles}
    )

    find_package(Qt6 REQUIRED COMPONENTS ShaderTools)

    qt_add_shaders(appCreatureWars creature_wars_shaders
        PREFIX "/"
        FILES
            shaders/outline.frag
            shaders/tint.frag
    )

    felgo_configure_executable(appCreatureWars)
    • qt_add_resources puts JSON and images into qrc:/, so they work on every platform. Example: "qrc:/data/economy.json".
    • qt_add_shaders compiles shaders to .qsb, which Qt 6 needs.
    • felgo_configure_executable links Felgo and prepares Android and iOS packaging.

    main.cpp

    Create FelgoApplication next to the QML engine and initialize it:

        QApplication app(argc, argv);

    FelgoApplication felgo;
    GameBackend game_backend;
    QQmlApplicationEngine engine;

    felgo.initialize(&engine);

    Pass your C++ object to QML and load the main file:

        engine.setInitialProperties({
        {QStringLiteral("gameBackend"), QVariant::fromValue(&game_backend)}
    });

    felgo.setMainQmlFileName(QStringLiteral("qml/Main.qml"));
    engine.load(QUrl(felgo.mainQmlFileName()));

    In QML the object is then a required property:

    GameWindow {
    required property var gameBackend
}

    Why not a context property? setContextProperty is the classic way, but required properties are checked by the QML compiler and are the recommended Qt 6 style.

    Note: The Felgo splash screen and a license message appear until you set PRODUCT_LICENSE_KEY in CMakeLists.txt.
