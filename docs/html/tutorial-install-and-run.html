    Tutorial 2: Install Felgo and Run the Game

    This chapter takes you from nothing to a running game.

    1. Install Felgo

    1. Go to felgo.com/download and create a free account.
    2. Download and start the Felgo installer.
    3. Select Felgo 4 with Qt 6.8.3. On Windows pick the MinGW 64-bit desktop kit.
    4. Finish the installation. It includes Qt Creator, CMake, Ninja and the compiler.

    2. Get the code

    git clone https://github.com/comm0/creature_wars.git

    3. Open the project

    1. Start Qt Creator from the Felgo installation.
    2. File > Open File or Project and select CMakeLists.txt.
    3. Select the Felgo Desktop Qt 6.8.3 MinGW 64-bit kit and click Configure Project.

    The first configure downloads nlohmann/json from GitHub, so you need internet.

    4. Build and run

    Select the appCreatureWars target and press Run (Ctrl+R). You get the start screen. Pick a race and press Start.

    In Debug builds a second window, Creature Wars Debug, shows log messages and the game tick time. That is normal.

    Note: Android is on the todo list. It is not tested yet, so this tutorial covers the desktop build only.

    5. Run the unit tests (optional)

    The core has its own tests that need no Felgo:

    cmake -S . -B build/core -DCREATURE_WARS_BUILD_APP=OFF -DBUILD_TESTING=ON
cmake --build build/core
ctest --test-dir build/core
