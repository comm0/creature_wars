    Tutorial 8: Selecting Units and Giving Orders

    Selecting

    Left click selects one unit, a drag selects many. Only your own race can be selected:

        function isOwn(group) {
        return playerGroup.length === 0 || group === playerGroup
    }

    Clicking your base selects it and keeps its menu open.

    Attack move

    The Attack move toggle in the bottom bar decides what a move order does:

    • On: units fight enemies on the way and then go on.
    • Off: units drop their target and just walk. Use it to retreat.

    A unit that only walks could get stuck and be killed without fighting back. So a blocked unit that was hit in the last two seconds gives up the move and fights:

        if (active_movement_goal_ == movement_goal_t::manual
        && !game_p.aggressive()
        && recently_hit(now_p)) {
        finish_manual_movement(game_p);
        return;
    }

    Outlines

    Selected units get a yellow outline around the sprite shape. Their target gets a red one:

    OutlineEffect {
    source: creatureSprite
    color: "#ff4a3d"
    visible: creatureView.targeted
}

    OutlineEffect captures the source with ShaderEffectSource and a shader colours transparent pixels next to opaque ones.
