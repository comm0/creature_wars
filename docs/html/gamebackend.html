    GameBackend Class

    The single object the QML client talks to. More...

    Header: #include <GameBackend>

    Detailed Description

    GameBackend creates game_t with the rules from data, owns the GameObserver and the list models for creatures, corpses, bases and base actions, and exposes the player's state as properties for the HUD.

    Its invokable functions such as startMatch(), walkCreature(), attackTarget() and orderBaseAction() forward player input to the core. The core validates every command, so the client cannot break the rules even by mistake.
