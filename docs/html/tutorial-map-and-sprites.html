    Tutorial 7: The Map, Sprites and Oblique Projection

    The tile map

    Tiles are 16 by 16 units. Each creature item covers one tile:

        x: column * tileSize
    y: row * tileSize
    width: tileSize
    height: tileSize

    A Behavior on x and y turns tile jumps into a smooth walk.

    Why Repeater and not a tile map editor? Felgo games often use Tiled maps. Our map is plain grass for now, so a Repeater is enough. A Tiled map is the way to go once the map gets terrain.

    Oblique projection

    Like in many classic 2D RPGs, height is drawn up and to the left. A sprite is 32 by 32, a tile 16 by 16, so we anchor the sprite's bottom right corner to the tile:

        readonly property real visualLeft: tileSize - spriteSize
    readonly property real visualTop: tileSize - spriteSize

    Objects further south or east are closer to the viewer and must be drawn on top:

        z: (x + y) / tileSize + y / tileSize / 1000

    Sprite sheets

    Each creature has 12 frames: 4 directions, one idle and two walking frames each. Felgo reads TexturePacker sheets directly:

                sourceComponent: TexturePackerSpriteSequence {
                id: creatureSprite

                readonly property string sheet:
                    CreatureSprites.sheetSource(creatureView.creatureTypeIdentifier)
                readonly property real walkFrameRate:
                    1000 / Math.max(100, creatureView.movementDuration / 2)

                running: creatureView.spriteWalking

                TexturePackerSprite {
                    name: "north_idle"
                    source: creatureSprite.sheet
                    frameNames: ["north_0.png"]
                }

    Switch animations by name:

    creatureSprite.jumpTo("south_walk")

    Note: Pack sheets with 1 pixel extrude and 2 pixels padding. Without it scaled pixel art shows thin lines at the frame edges.

    Screen densities

    Put each image in three sizes: normal, +hd (2x) and +hd2 (4x). Felgo picks one:

    assets/structures/base/base_1.png
assets/structures/base/+hd/base_1.png
assets/structures/base/+hd2/base_1.png

    Use the normal path in QML:

        MultiResolutionImage {
        id: baseImage

        x: -baseView.artHeight
        y: -baseView.artHeight
        width: baseView.width + baseView.artHeight
        height: baseView.height + baseView.artHeight
        source: "qrc:/assets/structures/base/base_" + baseView.artLevel + ".png"
        smooth: false
        layer.enabled: true
        layer.effect: TintEffect {
            color: baseView.baseColor
        }
    }

    One grey image, many colours

    Bases are grey. A tiny shader multiplies them with the race colour:

    void main()
{
    vec4 color = texture(source, qt_TexCoord0);
    fragColor = vec4(color.rgb * tintColor.rgb, color.a) * qt_Opacity;
}

    The grey art comes from scripts/generate_placeholders.py.
