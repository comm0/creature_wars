# creature_wars

Initial Creature Wars

Development rules:

- Backend C++ uses `snake_case`.
- Backend C++ types, classes, structs, enums, and type aliases use the `_t` suffix. `_p` for function parameters
- The QML frontend and the C++ API exposed to QML use Qt-style naming: `camelCase`


Current stack:

- Qt 6.8.3.
- Felgo 4.0.0.
- C++20.
- CMake 3.16 or newer.


Dispatcher based game (TFS like MMORPG monolith).
Currently reduced functionality to allow selfhosting offline strategy game.
Should be possible later to setup external server and act like game client (or let play offline)


Game development process powered&speed up by AI:

- Claude
